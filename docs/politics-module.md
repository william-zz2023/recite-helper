# 政治模块初版实现记录

这是逐页阅读初版的历史记录。当前专题连续阅读、手机排版和按题打卡的实现见 [政治阅读页改版](politics-reading-redesign.md)。

本次是现有界面的 Extension：保留音乐入口、原题库、音乐打卡键和备份格式；新增政治资料服务、阅读界面和独立的个人进度。

设计采用现有绿色学习工具语言。读者主要在手机近距离阅读，也兼顾电脑。页面以目录定位、正文阅读、主动确认复习为主；温和、安静，正文保持单列。

设计校准：视觉变化 2、动效 2、信息密度 6、图片依赖 1、既有风格保真 10。主色沿用 #0E9F6E，背景 #F4F5F7，白色阅读卡片；原系统字体，正文默认 18px、两倍行高。沿用 8/12/16/20/24px 间距、10–16px 圆角与细边框。只保留原有短暂入场反馈，遵循减少动态效果的系统设置。

## 数据流

1. 本机 Apple Vision 逐页识别扫描图，JSON 检查点保留识别文字、坐标和引擎置信度。
2. 整理脚本检查两册全部 406 个页码，清理重复水印及页眉，并定位分部和印刷页码。
3. 网站目录、上下册 JSON 与两个 TXT 来自同一份整理结果。
4. 浏览器按需加载当前分册；政治进度独立写入本机浏览器存储，不修改公开教材 JSON。

章节封面与正文起始页分开存储。上册第五部分没有在所给 PDF 中出现独立分部封页，目录直接定位 PDF 第 201 页正文，不能统一给分部位置加一。

## 保留与限制

- 政治页的导入、导出与音乐备份各自独立。存储错误时保留当前内存记录并提示导出，损坏的旧记录不会被覆盖。
- 复习确认按“本地日期、分册、PDF 页码”去重；翻页不代表复习完成，复习确认不代表掌握。
- 原始 PDF 保留在用户提供的位置，没有复制进网站，也没有上传到第三方 OCR 服务或 GitHub。
- 所有识别结果均未逐字校对；表格、框架图和数学符号的结构没有恢复。页面明确标注 OCR 来源，不生成自动判分题。
- 当前执行了 PDF 样页图片核对、模块/资源静态检查和 Node 回归测试；没有将这些检查表述为手机真机或浏览器验收。
