# 政治阅读页改版

依据用户确认的第二版产品图实现。保留既有绿色身份、音乐模块、原始逐页 OCR 与 TXT、原政治存储键、原 GitHub Pages 静态站点路径。

## 界面决策

模式为 Redesign · Preserve：安静的文字学习工作区，视觉变化 3、动效 1、信息密度 6、图片依赖 1、风格保真 9。主色 #0E9F6E，白色正文与浅灰导航，沿用系统中文字体。8px 间距节奏、12px 外框圆角、细边框，不增加装饰图片或统计卡片。

电脑采用固定侧栏与连续正文；手机正文单列，侧栏由目录按钮打开原生 dialog，支持浏览器模态焦点约束和 Escape 关闭。手机正文默认 16px／1.75 行高，题目 20px／1.45 行高，长题干 17px；关键词为紧凑的 12px 标签，段间距 10–12px，题间距 24px。底部操作有 44px 触摸高度和安全区域留白，正文底部预留空间。字号调整保留当前题目在视口的位置。

## 内容结构

阅读单位改为专题与题目，不再以 PDF 页码切断正文。来源页保持原文件结构：

- `upper.json`、`lower.json`：原始逐页识别文字、印刷页码与来源散列。
- `upper-reader.json`、`lower-reader.json`：专题、题目、段落／分点／选项／表格及来源页。
- `build-politics-reader.py`：从本地 OCR 坐标恢复相同行次序、拆出标题和题号，合并段落硬换行，支持跨页延续。逐行归属审计检查输入行没有遗漏分配。页面来源及 TXT 不改写。
- 部分已对照扫描图片的表格采用显式整理，修正跨行错配并合并续表。没有根据相似文字猜补缺失理论、公式或图表关系。

“原文出处”提供原始识别行序及 PDF／印刷页码，不冒充扫描图原文。复杂框架图仍是 OCR 识别结果，保留校对提示。这次整理不代表两册内容完成逐字校对。

## 持久化兼容

旧 `version: 1` 数据继续可读；新题目记录携带可选 `unitId`，`page` 保留来源起始页。同页多题分别去重，跨页同题只计一次；旧页级打卡保留，不自动转换成题目完成记录。书签、续读位置和导入／导出都保留兼容。音乐题库、音乐打卡键和判分没有变更。

新版字号默认 16px，独立存放在 `readerFontSize`；旧版字号字段保留以读取旧备份。存储损坏时不覆盖原值，写入失败时保留内存记录并提示备份。

## 验证范围

运行 Node 回归测试，新增连续阅读来源覆盖、跨页拼接、表格对应关系、选项次序、按题去重、混合旧备份和文本转义检查，并检查模块语法与本地资源请求。内容表格通过原 PDF 样页核对。未将这些检查当作真实 iPhone Safari 的浏览器验收，也未自动发布 GitHub。
