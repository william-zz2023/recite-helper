## 产品与样式边界

沿用音乐模块现有绿色与白色界面，模式为 Extension。阅读是主任务，复习清单位于底部；复习页按“题目 → 回忆 → 核对 → 反馈”排列，手机近距离阅读保持安静、紧凑。目录在手机默认收起，避免正文被长目录挤出首屏。

设计参数：变化程度 2/10、动效 2/10、密度 6/10、图片依赖 1/10、现有样式一致性 10/10。沿用 accent #0E9F6E、deep #0B7C57、soft #E6F7F0、背景 #F4F5F7、白色卡片、现有系统中文字体、16px 卡片圆角。正文 16px、手机题目 18px，主按钮至少高 44px，提示和分组使用较小字号；无外部字体、图片或新增运行依赖。

## 主要规则

1. 翻页仅保存阅读位置。用户确认已读后才写阅读打卡，并将题目加入清单；两者分别去重。移出清单不会撤销已经发生的阅读打卡。
2. 五题是节奏提示，不是门槛。清单非空即可开始；开始时复制准确的题目 ID 清单，不按当前章节重新生成。
3. 进行中的轮次不能被另一种模式或清单替换。暂存后新增题留到下一轮；已完成题可以再次加入，当前轮次完成不能删除这些新加入的题。
4. 默认口头背诵先只输出题目。可看关键词，展开答案后才能自评；“用过提示”保留在结果中。自评独立于自动计分，没有录音或语音识别。
5. 输入模式复用现有文字相似度，达到 80 分为通过。每题提交后显示差异，点下一题才前进。草稿上限 10000 字符，空白或仅标点不能提交。
6. 本轮小结的待巩固重练严格取本轮结果，不混入以前轮次的题。阅读页另有全部待巩固题入口。
7. 暂存返回到最近阅读位置，完成后接着读已确认题的下一题；末题不越界。章节范围和位置按题目 ID 保存。

## 实现分工

- `src/services/reading-review.js`：可注入存储、时间和编号生成器；清单、待巩固题、本轮进度及其校验、备份合并。读后复习使用独立存储键。
- `src/features/reading.js`：阅读位置、明确确认已读、清单与模式选择。
- `src/features/reading-review.js`：独立复习屏幕与固定题目侧栏，不改写原有的分批练习状态。
- `src/services/reading-review-history.js`：将已提交结果写入每日记录，通过稳定事件编号避免刷新重复写入。
- `src/services/study-history.js`：保留旧存储键，增加独立 `recall` 自评类型；只将书面作答计入自动判分的通过次数。
- `src/services/music-backup.js` 和 `src/shared/music-backup.js`：联合备份，先校验两部分后再合并；旧版备份仍适用。
- `src/styles/reading-review.css`：限定在阅读、复习和续背入口的样式，未修改政治文本或政治进度规则。

页面地址 `#music-reading` 和 `#music-review` 支持刷新后恢复。结果时间取实际提交时间，即使跨午夜恢复也写回原提交日。存储失败时保留本页数据、提示导出；已有损坏存储不自动覆盖，备份包含原始损坏字符串。

## 保留事项

用户数据按浏览器来源隔离，不提供账号或云同步。本地预览与正式网站数据不共享，可通过备份迁移。备份导入清单采用并集，较早备份可能恢复以前移出的题；当前未完成轮次优先保留。

原有填空题库占位编号及练习目录跨批跳转的已知问题不在本次功能范围。新复习流程使用独立进度，不走原有跨批跳转路径。
