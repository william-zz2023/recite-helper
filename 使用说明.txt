背诵助手：模块化版本

安装
将 index.html、src 文件夹、data 文件夹和 output/text 文件夹一起上传到 william-zz2023/recite-helper 仓库根目录并提交。不能只上传 index.html。GitHub Pages 部署完成后，用 Safari 刷新原网址。

本地预览
在本项目目录运行 npm start，或 python3 -m http.server 8000 --bind 127.0.0.1，然后打开 http://127.0.0.1:8000/。
不需要安装 npm 依赖。模块化版本需要 HTTP 预览，不再通过直接双击 HTML 打开。
代码目录与修改入口见 README.md。

打卡规则
1. 提交填空、问答或全文默写后，自动记录当天练过的题目、次数和最近得分。
2. 阅读原文后点击“本题已读，记入今日打卡”。只打开阅读页不会记为已读。同题当天重复确认只记一次。
3. 听读完整播放完一题后记录；播放失败、只开始播放或中途停止不记为听完。
4. 首页点击“查看打卡记录”，可切换日期、月份，查看题目明细及连续学习天数。当天题目数去重统计，不代表所有题目均已掌握。

保存与迁移
记录保存在当前浏览器的网站数据中，不会自动跨设备同步；无痕浏览、清理网站数据可能使记录丢失。
打卡页支持导出 JSON 备份，在另一浏览器导入。导入会合并日期及题目；同日同题同模式的次数取较大值，最近得分取较新记录。
本地 HTML、本地预览地址与 GitHub Pages 网页是不同存储位置；如果先在本地使用，请导出备份，在正式网页导入。
音乐打卡仍使用原来的存储键与 version: 1 备份格式；同一正式网址上的旧记录继续有效。

验证
运行 npm test，或 node --test tests/*.test.cjs。检查包括跨天记录、重复导入、保存失败和语音回调；测试直接调用拆分后的模块。
iPhone Safari 是否恢复声音还需要真机复测。

政治复习
首页顶部点击“政治复习”。正文按专题连续阅读，题目加粗、答案分点；支持上下册切换、题目目录、知识点搜索、字号调整、逐题遮答、收藏和续读。
手机默认正文 16px、题目 20px。点击左上角 ☰ 打开目录；返回音乐时，在目录底部点击“返回音乐背诵”。电脑宽屏可直接点击顶部“音乐背诵”。
点击“本题已背”才计入当天政治记录。同一页里的不同题目分别记录；跨页的同一道题当天只记录一次。打开页面、滚动和收藏不会自动打卡。
顶部“打卡记录”可按日期查看内容、导出和导入政治备份，与音乐备份分开保存和导入。旧版按页保存的记录和书签继续保留，不会自动变成整页所有题目均已背。
“原文出处”提供来源页的原始 OCR 文字、PDF 页码与原书页码，正文不再通过 PDF 页码翻阅。
两份 TXT 位于 output/text/，网页内也可下载。扫描 OCR 未逐字校对，公式、表格和个别字词请对照原 PDF；不据此自动判分。
原 PDF 未复制到网站，临时识别数据在 tmp/，不要上传到仓库。
